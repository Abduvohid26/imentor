iMentor — Tashqi API (partner integratsiya)
============================================

Hamkor tizimlar uchun to'liq qo'llanma.
Ikki blok: (A) Syllabus katalogi — kafedra/fan nomlari va mavzular;
           (B) Test bazasi — hodimlar yaratgan savollar.

Autentifikatsiya:  Header  X-Api-Key: <kalit>   (JWT kerak emas)
Server .env:       IMENTOR_EXTERNAL_API_KEYS=kalit1,kalit2
Base URL (prod):   https://imentor.devflix.uz/api
Base URL (local):  http://localhost:8080/api

Kalit yo'q / noto'g'ri → HTTP 403
Testlar 1 soatdan keyin e'lon qilinadi (yangi test → 404)


================================================================================
0. ENDPOINTLAR JADVALI (tez ko'rinish)
================================================================================

  KATALOG (nomlar + tuzilma, savolsiz)
  ───────────────────────────────────
  GET  /v1/external/catalog/stats/
  GET  /v1/external/catalog/departments/                              ← 1-qadam: kafedralar
  GET  /v1/external/catalog/departments/<department_code>/            ← 2-qadam: fanlar + yo'nalish + mavzular (TO'LIQ, bitta javobda)
  GET  /v1/external/catalog/subjects/<subject_code>/                  ← (ixtiyoriy) bitta fan, subject_code oldindan ma'lum bo'lsa
  GET  /v1/external/catalog/subjects/?department_code=...             ← (ixtiyoriy) qisqa ro'yxat/qidiruv, summary
  GET  /v1/external/catalog/departments/<department_code>/subjects/   ← (ixtiyoriy) sahifalangan summary ro'yxat

  TESTLAR (hodim yaratgan savollar)
  ─────────────────────────────────
  GET  /v1/external/tests/stats/
  GET  /v1/external/tests/
  GET  /v1/external/tests/<id>/
       ?question_limit=10..30
  GET  /v1/external/questions/sample/                                 ← unique aralashtirilgan savollar
       ?subject_code=...&department_code=...&count=10..30
       (+ ixtiyoriy variant_label, topic_code)


================================================================================
1. IERARXIYA VA KALIT MAYDONLAR
================================================================================

  Kafedra  →  Fan  →  Yo'nalish  →  Mavzu  →  Test savollari

  +------------------+--------------------------------------------------------+
  | Maydon           | Ma'nosi                                                |
  +------------------+--------------------------------------------------------+
  | department_code  | Kafedra kodi (masalan: fiziologiya)                     |
  | department_name  | Kafedra NOMI (masalan: Fiziologiya kafedrasi)          |
  | subject_code     | Fan kodi (masalan: fiziologiya__anatomiya)              |
  | subject_name     | Fan NOMI (masalan: Anatomiya)                           |
  | variant_label    | Yo'nalish (PI, DI, TPI, XT, St, …)                     |
  | topic_code       | Mavzu kodi (m1, l2, a3 — kichik harf)                  |
  | topic            | Mavzu sarlavhasi (insan tilida)                         |
  | syllabus_id      | Fan yozuvi PK (topic_norm dagi id bilan bir xil)        |
  | topic_norm       | {syllabusId}::{variant}::{topicCode}  masalan 12::pi::m1|
  +------------------+--------------------------------------------------------+

  Eslatma: subject_code va department_code — integratsiya uchun barqaror
  kalitlar. subject_name va department_name — foydalanuvchiga ko'rsatish uchun.


================================================================================
2. SAVOL SONI CHEGARASI (10 – 30)
================================================================================

  +------------------+------------------------------------------+
  | Parametr         | Vazifa                                   |
  +------------------+------------------------------------------+
  | question_limit   | Detail: nechta savol qaytarish (10–30)   |
  | question_count   | question_limit bilan bir xil (alias)     |
  | min_questions    | Ro'yxat: bazada kamida N ta savol        |
  | max_questions    | Ro'yxat: bazada ko'pi bilan N ta savol   |
  +------------------+------------------------------------------+

  Har bir test javobida:  "question_limit_bounds": { "min": 10, "max": 30 }

3.4  GET /v1/external/catalog/subjects/<subject_code>/
────────────────────────────────────────────────────────────
  Bitta fan, to'liq (3.3 dagi bitta "subjects[]" elementi bilan bir xil shakl).
  `subject_code`ni oldindan bilsangiz (masalan avvalgi so'rovdan saqlab
  qo'ygan bo'lsangiz) — kafedra bo'yicha qidirmasdan to'g'ridan-to'g'ri shu
  fanni olish uchun ishlatiladi.

  Misol: GET .../subjects/fiziologiya__anatomiya/


3.5  GET /v1/external/catalog/subjects/
───────────────────────────────────────
  Fanlar ro'yxati (summary — variants/topics'siz, faqat sonlar). Ko'p fanli
  kafedralarda tez ko'rish yoki qidiruv uchun.

  Query:
    department_code=fiziologiya   — faqat shu kafedra fanlari
    q=anatom                      — fan nomi/kodi bo'yicha qidiruv
    page=1
    page_size=50

4. TESTLAR API (B)
================================================================================

4.1  GET /v1/external/tests/stats/
──────────────────────────────────
  E'lon qilingan testlar statistikasi (1 soatdan eski).

  Javob (asosiy):
    totals.test_count, totals.questions_total
    totals.subjects_distinct, totals.variants_distinct, totals.topics_distinct
    by_subject[]   — fan NOMI + kafedra NOMI + test_count
    by_variant[]   — fan + yo'nalish + kafedra nomi
    by_topic[]     — mavzu bo'yicha
    by_author[]    — muallif bo'yicha
    recent[]       — oxirgi testlar (qisqa meta)
    question_limit_bounds

  by_subject[] element namunasi:
  {
    "subject_code": "fiziologiya__anatomiya",
    "subject_name": "Anatomiya",
    "department_code": "fiziologiya",
    "department_name": "Fiziologiya kafedrasi",
    "test_count": 5,
    "questions_total": 75,
    "variants_distinct": 2,
    "topics_distinct": 3
  }


4.2  GET /v1/external/tests/
────────────────────────────
  E'lon qilingan testlar ro'yxati (savolsiz — faqat meta).

  Query:
    subject_code=fiziologiya__anatomiya   — asosiy filter (YETARLI; yo'nalish/mavzu shart emas)
    variant_label=PI                      — ixtiyoriy
    topic_code=m1                         — ixtiyoriy
    syllabus_id=45
    q=yurak
    author=Ali
    sort=subject|topic|newest
    page=1
    page_size=50          (max 200)
    min_questions=10      (10–30)
    max_questions=30      (10–30)

  Eslatma: subject_code katalog formati (dept__fan) bo'lsa, legacy testlar
  (faqat kafedra kodi bilan saqlanganlar) ham qaytariladi — hamkor faqat
  kafedra+fan tanlab, ichidan random test olishi mumkin.

  Javob — har bir element:
  {
    "id": 42,
    "kind": "test",
    "topic": "Yurak anatomiyasi",
    "topic_norm": "45::pi::m1",
    "subject_code": "fiziologiya__anatomiya",
    "subject_name": "Anatomiya",
    "department_code": "fiziologiya",
    "department_name": "Fiziologiya kafedrasi",
    "variant_label": "PI",
    "topic_code": "m1",
    "syllabus_id": 45,
    "question_count": 25,
    "author_display_name": "Dr. Ali",
    "created_at": "2026-07-13T10:00:00+05:00",
    "is_published": true,
    "publish_at": "2026-07-13T11:00:00+05:00",
    "document_id": "IM-000042-AB12CD34",
    "verification_code": "A1B2C3D4E5F6G7H8"
  }

─────────────────────────────────

    question_count=20   — alias

    "question_limit": 20,
    "question_count_available": 25,
    "question_count_returned": 20,
    "question_limit_bounds": { "min": 10, "max": 30 },
    "document_id": "IM-000042-AB12CD34",
    "verification_code": "A1B2C3D4E5F6G7H8",
    "payload": {
      "topic": "Yurak anatomiyasi",
      "questions": [
        {
          "question": "45 yoshli bemor ...",

              "question": "Пациент 45 лет ...",

  Eslatma: "optionExplanations" — options bilan bir xil tartibda, har bir variant
  uchun alohida qisqa izoh (nega to'g'ri / nega xato). Eski testlarda (bu maydon
  qo'shilishidan oldin yaratilgan) bu maydon bo'lmasligi mumkin — ixtiyoriy
  maydon sifatida ishlating.

  Eslatma: "translations" — test yaratilgan tildan (topic/questions'dagi asosiy
  til) TASHQARI qolgan 2 tildagi to'liq versiyalar (uz/ru/en — jami 3 til,
  har doim shu uchtasi). Har bir til kaliti ostida xuddi shu shakl:
  {topic, questions[]}. correctOptionIndex barcha tillarda bir xil (faqat matn
  tarjima qilingan, faktlar o'zgarmagan). Agar tarjima muvaffaqiyatsiz bo'lsa
  (kamdan-kam), shu til kaliti "translations" ichida bo'lmasligi mumkin — buni
  ixtiyoriy/qisman to'liq maydon sifatida ishlating. Eski testlarda (bu funksiya
  qo'shilishidan oldin yaratilgan) "translations" umuman bo'lmaydi.


4.4  GET /v1/external/questions/sample/
──────────────────────────────────────
  Kafedra/fan doirasidagi BARCHA e'lon qilingan testlardan unique savollarni
  aralashtirib, so'ralgan sondagi namunani qaytaradi.
  (Bitta test tanlash + prefix emas — pool + shuffle + unique.)

  Majburiy (kamida bittasi):
    subject_code=fiziologiya__anatomiya
    department_code=fiziologiya

  Ixtiyoriy:
    count=20            — 10–30 (alias: question_limit, question_count)
                          berilmasa → unique poolning hammasi
    variant_label=PI
    topic_code=m1
    syllabus_id=45

  Unique: savol matni (lower + whitespace normalize). Bir xil matn ikki marta
  chiqmaydi. Savolda references bo'lmasa — shu testning payload.references
  o'tkaziladi (static kitob yozilmaydi).

  Misol:
    GET /api/v1/external/questions/sample/?subject_code=fiziologiya__anatomiya&count=20
    Header: X-Api-Key: <kalit>

  Javob:
  {
    "subject_code": "fiziologiya__anatomiya",
    "department_code": "",
    "variant_label": "",
    "topic_code": "",
    "syllabus_id": "",
    "count_requested": 20,
    "count_available": 87,
    "count_returned": 20,
    "tests_scanned": 5,
    "question_limit_bounds": { "min": 10, "max": 30 },
    "questions": [
      {
        "question": "45 yoshli bemor ...",
        "options": ["A", "B", "C", "D", "E"],
        "correctOptionIndex": 2,
        "explanation": "...",
        "references": [
          { "title": "Oxford Textbook of Palliative Medicine", "pages": "501, 818" }
        ],
        "source_test_id": 24
      }
    ]
  }

  Xatoliklar:
    400 — subject_code va department_code ikkalasi ham yo'q
    400 — count 10–30 dan tashqari
    403 — X-Api-Key yo'q/noto'g'ri

5. INTEGRATSIYA OQIMI (tavsiya etilgan ketma-ketlik)
================================================================================

  1. Kalit olish
     Administrator: IMENTOR_EXTERNAL_API_KEYS=hamkor-kalit

  2. Katalog hajmi
     GET /v1/external/catalog/stats/
     → 28 kafedra, 230 fan, 281 yo'nalish, 4848 mavzu

  3. Kafedra ro'yxati
     GET /v1/external/catalog/departments/
     → kafedra name + code ro'yxati

  4. Fanlar (yo'nalish/mavzu — ixtiyoriy)
     GET /v1/external/catalog/departments/fiziologiya/
     → shu kafedradagi barcha fanlar (+ ixtiyoriy variants/topics)
     Hamkor uchun MINIMAL oqim: kafedra → fan → testlar.
     Yo'nalish (variant_label) va mavzu (topic_code) SHART EMAS —
     faqat subject_code bilan ham testlar topiladi (ichidan random).

  5. Test bormi?
     GET /v1/external/tests/stats/
     → by_subject da department_name + subject_name

  6. Test id topish (tavsiya: faqat fan)
     GET /v1/external/tests/?subject_code=fiziologiya__anatomiya
     → shu fan (va legacy bo'lsa kafedra) dagi e'lon qilingan testlar
     Ixtiyoriy toraytirish:
     GET /v1/external/tests/?subject_code=...&variant_label=PI&topic_code=m1

  7. Savollarni import
     GET /v1/external/tests/42/?question_limit=20

  8. (Ixtiyoriy) Manba tasdiqlash
     document_id + verification_code saqlash


  Integratsiya tavsiyasi (imtihon yaratish):
    1) catalog/departments/ → kafedra
    2) catalog/departments/<code>/ → fan (+ variant/mavzu)
    3) questions/sample/?subject_code=...&count=20  ← unique aralash bank
       (eski yo'l: tests/ list → tests/<id>/ ham ishlayveradi)

  curl misol (sample):
    curl -sS -H "X-Api-Key: $KEY" \
      "$BASE/v1/external/questions/sample/?subject_code=ANAT-CAT&count=10"

6. curl MISOLLARI
================================================================================

  # Katalog statistikasi (kafedra/fan nomlari bilan)
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/catalog/stats/"

  # Kafedralar ro'yxati (nom + kod)
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/catalog/departments/"

  # Bitta kafedra + uning fanlari
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/catalog/departments/fiziologiya/"

  # Fanlar (kafedra bo'yicha filter)
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/catalog/subjects/?department_code=fiziologiya&page_size=100"

  # Fan tafsiloti (yo'nalish + mavzular)
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/catalog/subjects/fiziologiya__anatomiya/"

  # Test statistikasi
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/tests/stats/"

  # Testlar — faqat fan (yo'nalish/mavzu shart emas; ichidan random tanlash mumkin)
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/tests/?subject_code=fiziologiya__anatomiya"

  # Testlar (ixtiyoriy: fan + yo'nalish + mavzu)
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/tests/?subject_code=fiziologiya__anatomiya&variant_label=PI&topic_code=m1"

  # Kamida 15 savolli testlar
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/tests/?min_questions=15"

  # 20 ta savol bilan bitta test
  curl -s -H "X-Api-Key: YOUR_KEY" \
    "https://imentor.devflix.uz/api/v1/external/tests/42/?question_limit=20"
